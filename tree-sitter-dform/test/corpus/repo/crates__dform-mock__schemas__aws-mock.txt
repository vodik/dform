# Mock AWS provider in the shape of the Terraform AWS provider (v5 schema),
# twelve resource types, written by hand from the provider's schema. It exists
# to make two shapes concrete for the phase 2 decisions:
#
#   - Optional+Computed (optional_computed): the program may set the attribute;
#     when it does not, AWS picks it at Apply (an instance's subnet_id and
#     availability_zone, a security group's vpc_id, a bucket's name).
#   - keyless sets (type set, no type_list_key): security group ingress and
#     egress, route table routes, vpc_security_group_ids. Element order is
#     not a change; an element has no identity but its whole content.
#   - force_new: changing a vpc's or subnet's cidr_block, a subnet's zone or a
#     bucket's name replaces the object, as the provider's RequiresReplace does.
#   - type_replace: an instance's replacement is created first; a bucket's
#     name is global, so the old bucket is destroyed first.
#   - name_like: a name_prefix names the object in the account, as `name`
#     and `bucket` do; a keyed stack's deployments must not share one.
#
# Every type has tags (optional) and tags_all (computed: tags merged with the
# provider's default_tags). ids and arns are computed; ids are fresh.

edition 2026
