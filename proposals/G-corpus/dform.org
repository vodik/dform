* Notes on dform.df

** Lowering, where it is not obvious

- =let cfg = settings[env]= is a reference alias, not a value. Each rule that
  says =cfg.a.b= gets one =env(E)= literal and one =setting(E, .a.b, V)=
  literal per distinct path, exactly the literals the current instance
  bodies write.
- =vpc_peer(a, b) if ..., a = network[ia].vpc= is =output(network.IA, vpc, A)=:
  =network[ia]= is today's =network.I= instance scope (=format("network.%s", I)=).
- The peering block's =for= and =if= clauses are the body; its name
  ="peer-{ia}-{ib}"= becomes =Peer = format("peer-%s-%s", IA, IB)= appended
  last, as the current rule writes it. =a in net.vpc= is =want(net.vpc, A)=
  with =A= already bound: a check that also gives =a= the static type
  =net.vpc=, which is what lets =a.id= mean =ref(net.vpc, A, .id)=.
- =constraint ... if env == "prod", exists database.main/db, not database.main/db.multi_az=
  is =env(prod), want(db.postgres, database.main/db), not attr(db.postgres, database.main/db, multi_az, true)=.
  The type =db.postgres= comes from module =database='s declaration of =db=.
- The scenario's second deny has no =exists=: the current one has no =want=
  either, so a prod plan with no database denies. Kept.
- =_ in db.postgres= is =want(db.postgres, _)=.

** Reads better

- The instance blocks: =multi_az = cfg.db.multi_az= instead of a variable
  named in the block and bound four lines below it. 17 of the 19
  read-carrier variables in this file are gone (the two left, =a= and =b=
  in =vpc_peer=, are the relation's columns).
- Constraints say what they check: =not database.main/db.multi_az=.
- Scenarios: =with env = "prod"= and =not "peer-main-peer" in net.vpc_peering=.

** Reads worse

- Twelve symbol constants became strings (="prod"=, ="app"=, ="audit.write"=,
  ="strict"=). Two more characters each; nothing else changes.
- =exists database.main/db= must be written by hand; the Prolog form made
  the same =want= literal just as explicit, but a reader of the new form may
  expect =not database.main/db.multi_az= to mean "the database exists and is
  not multi-AZ". It does not (G-13).
- =settings e @default { for env_name(e) ... }=: whether the header name is a
  variable depends on the =for= clause binding it (G-9).
- =network[ia].vpc= is an instance output (the interface), =database.main/db=
  is a resource inside an instance (piercing it). One character apart.

** Found while rewriting

The peering rule joins =vpc_peer_inst(IA, IB)= and =vpc_peer(A, B)= without
connecting them: with a second peering edge it would create four peerings,
two of them misnamed. The rewrite keeps the cross product (it must lower to
the same AST); the fix is =vpc_peer(ia, ib, a, b)=, a separate ticket.

policy baseline {
  # Grants are partition patterns: this pack writes .tags of every type,
  # iam.policy's .statements and settings' .audit.sinks, and nothing else.
  contributes arg to _ at .tags.
  contributes arg to iam.policy at .statements.
  contributes arg to settings at .audit.sinks.

  # Lattices for paths several authors contribute to. Object paths such as
  # `tags` are maps by default; a list is one value unless declared a set.
  type_lattice(iam.policy, .statements, set).
  type_lattice(settings, .audit.sinks, set).

  # Example: add a shared tag to everything.
  arg(Type, Name, .tags, { team: platform }) :-
    want(Type, Name).

  # Example: policy pack can contribute directly to an IAM policy. Reads
  # .name of the type it writes .statements on: legal under (type, path)
  # partitions.
  arg(iam.policy, Policy, .statements, [{ action: org.read, resource: "org" }]) :-
    env(prod),
    want(iam.policy, Policy),
    attr(iam.policy, Policy, .name, app).

  deny("db must not be public", { resource: Db }) :-
    want(db.postgres, Db),
    not attr(db.postgres, Db, .public, false).

  # Example warning: prod should enable an audit setting.
  warn("prod should enable audit logging", { env: prod }) :-
    env(prod),
    not setting(prod, .audit.enabled, true).

  # Example: policy pack can add a sink without owning the whole list.
  arg(settings, prod, .audit.sinks, ["s3"]).

  # Networking invariants live in `modules/stdlib_net.df`.
}.

policy baseline {
  # Grants are partition patterns: this pack writes .tags of every type,
  # iam.policy's .statements and settings' .audit.sinks, and nothing else.
  contributes _.tags
  contributes iam.policy.statements
  contributes settings.audit.sinks

  # Lattices for paths several authors contribute to.
  type_lattice(iam.policy, .statements, "set")
  type_lattice(settings, .audit.sinks, "set")

  # A shared tag on everything.
  r.tags = { team: "platform" } if r in resource

  # A pack can contribute directly to an IAM policy. Reads .name of the
  # type it writes .statements on: legal under (type, path) partitions.
  p.statements = [{ action: "org.read", resource: "org" }] if {
    env == "prod"
    p in iam.policy
    p.name == "app"
  }

  deny "db must not be public" { resource: pg } if pg in db.postgres, not pg.public == false

  # Prod should enable an audit setting.
  warn "prod should enable audit logging" { env: "prod" } if {
    env == "prod"
    not settings.prod.audit.enabled
  }

  # A pack can add a sink without owning the whole list.
  settings prod { audit.sinks += ["s3"] }

  # Networking invariants live in `modules/stdlib_net.df`.
}

*** Lowering, where it is not obvious

- Module input names are value names (G-12): =cidr = vpc_net= in module
  =network= is =vpc_net(V)= in the block's body, as today. =has backup_days=
  is =backup_days(_)=.
- =inet_subnet(vpc.cidr, 4, zone_index[z])=: =vpc.cidr= is an argument of a
  builtin, so it is read now, =attr(net.vpc, vpc, cidr, V)=; =zone_index[z]=
  is =zone_index(Z, I)=. Both are hoisted into the block's shared body, so
  they gate the whole subnet (the want and every field), exactly as today's
  body does (F10).
- =vpc_id = vpc.id= is a whole field value, so it is a reference:
  =ref(net.vpc, vpc, .id)=, the fresh null plus the apply-order edge.
- =[ s.id | s in net.subnet, s.visibility == "private" ]= is today's
  comprehension literal for literal.
- In =baseline=, =r.tags = { team: "platform" } if r in resource= is
  =arg(T, R, .tags, {team: platform}) :- want(T, R)=: a contribution whose
  type is a variable. =contributes _.tags= is =contributes arg to _ at .tags=.
- =not pg.public == false= is =not attr(db.postgres, Pg, public, false)=:
  absent, true, or anything else but =false= denies.
- =not settings.prod.audit.enabled= is =not setting(prod, .audit.enabled, true)=.
- =settings prod { audit.sinks += ["s3"] }= inside the pack lowers to the
  same =arg(settings, prod, "audit.sinks", ["s3"])= the fact writes.

*** Reads better

- =iam=: =role_id = app_role.id= says what the Prolog form said with a type,
  a name and a keypath.
- =network=: the subnet reads as Terraform reads, name first, then fields;
  the only join the reader must see is =zone_index[z]=, and the brackets
  mark it.
- =stdlib_net=: =inet_overlaps(a.cidr, b.cidr)=; half the tokens.

*** Reads worse

- =subnet_ids = subnet_ids= in module =database=: field key and input share
  a name. Legal and unambiguous (the left side is a key), but it reads like
  a no-op.
- =contributes _.tags= is new notation for a grant pattern; the Prolog form
  spelled the partition out (=arg to _ at .tags=).
- =type_lattice(iam.policy, .statements, "set")= keeps a keypath literal:
  facts about paths still take paths.
- A local resource named =db= next to the type namespace =db= (=db.postgres=):
  in a term, =db.id= is the resource (locals first); after =in=, =db.postgres=
  is the type (types first). Legal, and a trap; =dform lint= should warn.
