* Notes

** Lowering, where it is not obvious

- =project(cfg.project_id, cfg.project_name, cfg.region, "projects/...")= is
  a head whose arguments read settings: it lowers to today's rule, with the
  =format= in the head instead of bound by =NetId = ...= in the body.
- =token: google.client_config["current"].access_token=: the type has no
  provider (a data source), so the reference is the null itself, as today.
  =T["current"]= because nothing declares =current=; =T.name= requires a
  declared resource (G-5).
- =if ns = k8s.namespace.pngu.name= then =namespace = ns=: the current
  program reads the namespace's name in the body (=arg(...)= in a body is
  =attr=), not by =ref=. =namespace = k8s.namespace.pngu.name= would be a
  reference and would print =ref(k8s.namespace,pngu,name)= in the plan,
  because =name= is not computed under the gke schema (a
  =Value::Ref= to a configured attribute). The rewrite keeps the read so
  the plan stays byte-identical, and the difference is the one this
  proposal is most worried about (section 9).
- A bare =pngu= would be ambiguous (a cluster and a namespace share the
  name), so every reference says its type: =gke_cluster.pngu.zones=.
- =for z in gke_cluster.pngu.zones= is =attr(gke_cluster, pngu, zones, Zs),
  member(Zs, Z)=: the content position over an open null that makes the
  node pools a pending group. Nothing in the syntax says so.
- =zone_count(count(z)) if z in gke_cluster.pngu.zones=: aggregates stay in
  heads (G-16).

** Reads better

- =cluster = gke_cluster.pngu.id=, =host: gke_cluster.pngu.endpoint=: the
  reference reads as the plan prints the address (=gke_cluster.pngu=).
- The denies: =exists gke_cluster.pngu, zone_count(n), n < 2=;
  =c in gke_cluster, not c.deletion_protection=.

** Reads worse

- The phase structure is invisible. In the Prolog form a reader could at
  least see =ref(gke_cluster, pngu, .endpoint)= and ask what =ref= does; in
  the new form =gke_cluster.pngu.endpoint= looks like any value. Which
  references are open nulls is schema knowledge either way; the LSP must
  show it (an inlay =?open= on the reference).
- The two =if ns = ...= clauses exist only to choose a read over a reference.
